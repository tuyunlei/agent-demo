# 005 - 语音交互（方向记录，待深入）

*2026-02-16 讨论*

## 未来方向

Agent 支持语音交互，两种场景：

- **语音消息**（非实时）：用户录一段发给 agent，agent 回一段语音。gRPC 能覆盖，用 bytes 类型传音频文件即可。
- **实时语音对话**（像打电话）：需要低延迟，gRPC (TCP) 不适合，需要 WebRTC 或类似 UDP 方案。

## 架构影响

- 语音消息：不影响现有架构，只是多一种消息类型 + STT/TTS 服务
- 实时语音：需要独立的音视频通信链路，不走 gRPC
- MVP 不做，但 Message 数据模型可以预留多媒体类型字段
